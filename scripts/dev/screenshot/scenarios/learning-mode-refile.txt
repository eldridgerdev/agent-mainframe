# learning-mode-refile: Learning Mode end to end on a repo the user did
# not write — open with K, read the first-visit help, browse the pinned
# Start here group, select a range, ask an explaining question, wait for
# the real headless answer, then re-file the entry as a change request
# with `i` (docs/backlog/learning-mode-plan.md, Epic 5).
#
# Needs a seeded project + feature, and asks a real question, so the
# harness must be authenticated:
#   ./amf-capture.sh --scenario scenarios/learning-mode-refile.txt \
#       --seed <project.json> --seed-feature <feature.json> \
#       --geometry 140x44
#
# 140x44 on purpose: the answer pane's footer drops its `i` hint at 120
# columns, which is exactly the key this scenario is proving.

shot:dashboard
