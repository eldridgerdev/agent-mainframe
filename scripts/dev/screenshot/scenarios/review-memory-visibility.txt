# Review memory: Add to Memory requires a destination, and AI Review shows
# which memory docs it will read and what the last run sent.
#
# Offline fixture: seeds a demo project + feature, a pr_review_cache row for
# this branch's own PR (so PR Triage shows a hand-written comment with no live
# comment fetch), two scratch review-memory docs, and a completed AI Review
# cache row whose attribution records the memory a "last run" sent. No agent
# is spawned and nothing is written to GitHub; the one finding appended goes
# to the scratch project doc.
#
# Requires this branch to have an open PR. In GitHub Actions,
# AMF_SCREENSHOT_PR_NUMBER and GITHUB_REPOSITORY are set by
# amf-screenshot-artifact.yml; for a local run, export both first.

run:printf '{"path":"%s","project_name":"review-memory-demo","dry_run":false}\n' "$REPO_ROOT" > "$XDG_STATE_HOME/memory-project.json"
run:$AMF_BIN automation create-project --file "$XDG_STATE_HOME/memory-project.json"
wait:900
run:python3 scripts/dev/screenshot/seed-memory-ai-summary-fixture.py "$XDG_CONFIG_HOME/amf/amf.db" "$REPO_ROOT" "$AMF_SCREENSHOT_PR_NUMBER"
run:python3 scripts/dev/screenshot/seed-review-memory-fixture.py "$XDG_CONFIG_HOME" "$XDG_STATE_HOME" "$REPO_ROOT" "$AMF_SCREENSHOT_PR_NUMBER" "$GITHUB_REPOSITORY"
wait:400

# Restart the TUI so it reads the seeded project, feature, cache rows and the
# config pointing at the scratch memory docs.
run:tmux respawn-pane -k -t "$SESSION" "$AMF_BIN"
run:for i in {1..60}; do tmux capture-pane -p -t "$SESSION" > "$XDG_STATE_HOME/memory-pane.txt"; grep -q "review-memory-demo" "$XDG_STATE_HOME/memory-pane.txt" && break; sleep 0.2; done
wait:6000

key:l|wait:400
key:j|wait:400
key:G|wait:4000
key:M|wait:400
expect:Add to memory
expect:nothing is selected yet
expect:[p] ○ project
expect:[g] ○ global
expect:review-memory/project.md
expect:review-memory/global.md
expect_not:Add to project memory
note:Add to Memory now opens with no destination selected. Both the project doc and the cross-project doc are listed with their full paths, so you can see where the finding would go before choosing.
shot:memory-add-no-destination

key:Enter|wait:400
expect:Choose where to save first
expect:[p] ○ project
note:Pressing Enter before choosing saves nothing. The dialog stays open and says why, instead of quietly writing to a default doc.
shot:memory-add-enter-refused

key:p|wait:400
expect:Add to project memory
expect:[p] ● project
expect:[g] ○ global
expect_not:Choose where to save first
note:Pressing p selects the project doc. The title and the marked row both name the destination, and the warning clears.
shot:memory-add-project-selected

key:Enter|wait:300
expect:Added to project memory
note:Enter now saves the finding, and the confirmation names the doc it was written to.
shot:memory-added-toast

run:$AMF_BIN automation seed-ai-review --file "$XDG_STATE_HOME/ai-review-fixture.json" >/dev/null
wait:600
expect:Memory
expect:● project 4 findings
expect:review-memory/project.md
expect:● global  2 findings (+1 already in project)
expect:last run sent 5 memory findings (project 3 + global 2) to the agent
note:The AI Review pane lists the memory docs the next review will read, with each path and finding count. The project doc already includes the finding just added, and the global doc's repeat of a project finding is counted once. The line below records what the last completed run actually sent to the agent.
shot:ai-review-memory-block
