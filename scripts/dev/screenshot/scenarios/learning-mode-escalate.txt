# learning-mode-escalate: the one door out of Learning Mode's read-only
# promise. Open with K, browse to a file, select a range, ask an
# explaining question, wait for the real headless answer, then press `S`
# to hand it to a live agent — check a real session starts, the composer
# opens pre-filled with the anchor + question + answer, and nothing is
# sent. Pressing `S` again must return to that session rather than
# starting a second one.
# (docs/backlog/learning-mode-plan.md, Epic 5.)
#
# Needs a seeded project + feature, asks a real question, and launches a
# real agent session, so the harness must be authenticated:
#   ./amf-capture.sh --scenario scenarios/learning-mode-escalate.txt \
#       --seed <project.json> --seed-feature <feature.json> \
#       --geometry 140x44

shot:dashboard

# documented there, and "Worth knowing" says what it crosses.
